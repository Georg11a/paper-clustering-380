这三个页面到底做了什么？

三个页面都把 282 篇论文一次性放在一起，不再按原始 keyword group 分开聚类。 它们共享同一批论文和同一组 BGE-M3 向量，只改变“是否先用 UMAP 降维”以及“使用哪种聚类算法”。

直白结论：这些结果现在只能用于比较和提出假设，还不能宣布哪一个是最终正确的主题结构。 Page 1 的密度方法留下了很多 noise；Page 2 和 Page 3 虽然几乎消除了 HDBSCAN noise， 却都压成了非常不平衡的两个大簇（55 / 227）。这不是“UMAP 已经解决问题”的证据， 只是说明参数和表示空间改变后，算法给出了另一种切分。

显示不等于计算

所有散点图使用单独的 2D UMAP 只负责显示。图上的 UMAP 1 / UMAP 2 没有可解释语义，也不一定是实际聚类空间。

文本和 embedding

每篇论文的表示来自 title、abstract 和最多 12 个与检索关键词相关的 passage。 BGE-M3 输出 1024 维向量；代码随后做 L2 normalization。BGE-M3 的原论文说明该模型面向多语言、 多粒度文本与检索任务，但这只支持“它是合理的语义表示候选”，不保证它会为本语料形成可解释聚类。 参见 Chen et al. (2024)。

共同评价指标

  • cluster count：不含 noise 的簇数。
  • coverage：被密度方法分到某个簇的论文比例；K-Means 强制分配全部论文，所以永远是 100%。
  • noise：标签 -1。界面显示为 “Noise / weak affinity”，不会硬塞回最近的簇。
  • original-space cosine silhouette：回到原始 1024D BGE-M3 空间，用 cosine distance 计算。 对 DBSCAN / HDBSCAN，只在非 noise 论文上计算。
  • cluster size：最小簇与最大簇，用来阻止算法选出大量极小碎片。
必须注意：密度方法的 silhouette 排除了 noise。所以 HDBSCAN 把最难分的 228 篇论文排除后， 剩下 54 篇的 silhouette 可以变高。不能只看 0.286，而不同时报告 19.1% coverage。

1所有论文直接在原始 embedding 空间聚类

一句话：不让 UMAP 改写几何结构，直接对 282 × 1024 的 normalized BGE-M3 向量运行三种算法。 这是最直接的 baseline。

K-Means 是怎么实现的

  1. 测试 k ∈ {2, 3, 5, 6, 8, 10, 12}。
  2. 每个 k 使用 n_init=50，固定 random_state=20260730，减少单次随机初始化碰巧很差的风险。
  3. K-Means 最小化点到质心的平方欧氏距离，因此会把每一篇论文都分到某个簇；它没有 noise 概念。
  4. 当前选择规则挑出 k=3：3 簇、尺寸 50–130、coverage 100%、原始空间 cosine silhouette 0.0927。

研究依据：Lloyd 的经典工作给出了迭代式最小平方量化条件， 是 K-Means/Lloyd algorithm 的理论来源之一 （Lloyd, 1982）。 它是必要 baseline，因为简单、可复现，并明确测试“数据是否大致能被球形质心切开”。

问题：silhouette 只有 0.0927，说明分离度很弱。K-Means 仍然会强制给所有论文标签， 所以“0 noise”不是质量证据。它偏好大小相近、近似球形的簇，而论文主题可能重叠、大小不等。

DBSCAN 是怎么实现的

  1. 在 normalized 1024D 向量上使用 cosine distance。
  2. 测试 min_samples ∈ {3, 5, 8, 10}。
  3. 对每个 min_samples，从 k-nearest-neighbor distance 的 25%–92% 分位数生成 28 个候选 eps。
  4. 当前选中 eps=0.1432, min_samples=5：2 簇、164 noise、coverage 41.8%、silhouette 0.2132。

研究依据：DBSCAN 的原论文强调三个目标：不预先给定簇数、发现任意形状的簇、 并把稀疏点视为 noise （Ester et al., 1996）。 这正好检验“论文之间是否存在密集语义岛，而其余论文只是弱连接”。

问题：DBSCAN 用一个全局 eps 描述所有簇的密度。当不同主题密度差异大时，一个 eps 很难同时适合。 本结果只覆盖 118 篇，另外 164 篇是 noise。它告诉我们 raw embedding 中没有很强的统一密度结构； 它不是 282 篇论文的完整分类。

HDBSCAN 是怎么实现的

  1. 在 normalized 1024D 向量上使用 Euclidean distance。对单位向量， squared Euclidean distance 与 cosine distance 单调对应，但数值尺度仍不同。
  2. 测试 min_cluster_size ∈ {5, 8, 10, 12, 15, 20}。
  3. 测试 min_samples ∈ {1, 3, 5, 8, 10}，并要求 min_samples ≤ min_cluster_size。
  4. 当前选中 min_cluster_size=8, min_samples=8：2 簇、228 noise、coverage 19.1%、silhouette 0.2864。

研究依据：HDBSCAN 从不同密度尺度建立层级结构，再依据稳定性提取簇； 它不要求预先指定 k，也允许样本保持为 noise （Campello, Moulavi & Sander, 2013； Campello et al., 2015）。

问题，但不是简单的“缺点”：80.9% noise 表示大多数论文没有稳定地属于当前参数下的高密度核心。 这可能是重要发现：语料更像连续的、交叠的研究空间，而不是清晰主题岛。 但如果产品目标是“给每篇论文一个主题”，这个配置就不够用。

2先用 UMAP 降维，再比较三种算法

一句话：先把 1024D embedding 压到 5D，再在这 5D 空间分别运行 K-Means、DBSCAN、HDBSCAN。 这直接测试老师提出的“高维空间可能让密度聚类产生过多 noise”。

UMAP → 5D
K-Means / DBSCAN / HDBSCAN
回原始 1024D 评价

UMAP 的实际参数

  • n_components=5：聚类使用 5D，不是图上看到的 2D。
  • n_neighbors=15：每个点构建局部邻域时参考 15 个近邻。
  • min_dist=0.0：允许近邻在低维空间靠得非常紧，便于密度方法形成簇。
  • metric="cosine"：原始 embedding 的邻近关系由 cosine distance 构建。
  • random_state=20260730、n_jobs=1：让这次生成可复现。

研究依据：UMAP 是一种基于邻域图的非线性降维方法，可生成超过 2D 的表示， 因此可作为下游机器学习的低维输入 （McInnes, Healy & Melville, 2018）。 BERTopic 也公开了“transformer embeddings → UMAP → HDBSCAN → class-based TF-IDF”的文档聚类路线 （Grootendorst, 2022）。 这些研究支持尝试这种 pipeline，不是证明它一定优于 raw-space clustering。

三个输出

K-Means · 5D

k=2；2 簇，55 / 227；0 noise；silhouette 0.0814。

直说：比 raw K-Means 的 0.0927 更低，而且产生一个很大的主簇。没有改善证据。

DBSCAN · 5D

eps=0.2374, min_samples=5；15 簇；163 noise；coverage 42.2%；silhouette 0.1958。

直说：出现更多小簇，但 noise 几乎没减少；最小簇只有 5 篇，可能碎片化。

HDBSCAN · 5D

min_cluster_size=15, min_samples=8；2 簇，55 / 227；0 noise；silhouette 0.0814。

直说：noise 从 80.9% 变成 0%，但换来一个非常粗的 55 / 227 二分。

关键风险：UMAP 会重建局部邻域，也会改变距离和密度。 densMAP 论文明确指出普通 UMAP 并不保存原空间的局部密度，这对后续依赖“密度”的 DBSCAN/HDBSCAN 尤其重要 （Narayan, Berger & Cho, 2021）。 所以“UMAP 后 noise 少”可能来自几何压缩，不等于真实主题更清楚。

我们实际运行的参数

  • UMAP：n_components=10、n_neighbors=15、min_dist=0.0、 metric="cosine"、random_state=20260730。
  • HDBSCAN 使用与前面相同的候选网格。
  • 当前选中：min_cluster_size=15, min_samples=1。
  • 结果：2 簇，55 / 227；0 noise；原始空间 cosine silhouette 0.0814。

它与文章的关系

Zhicheng 分享的 Vizuara 教程 推荐“文本 embedding → UMAP 降维 → HDBSCAN → 人工抽样检查 → UMAP 可视化”。 教程的 Part 2 也明确展示了从 1024D 到 10D 的 UMAP，然后用 HDBSCAN 聚类。 这与 BERTopic 的研究 pipeline 同方向，因此不是凭空组合。

但这不是对教程的精确复现。教程使用不同语料、不同样本规模和参数； 我们有 282 篇论文，并通过当前候选评分选择 min_cluster_size=15, min_samples=1。 Vizuara 是实作教程，不是同行评审论文。它告诉我们“怎么试”，不能替我们验证结果。

当前最明显的问题

  • min_samples=1 很宽松，几乎不要求一个点拥有高密度邻域，因此 0 noise 并不意外。
  • 结果与 Page 2 的 5D HDBSCAN 都是 55 / 227，且 silhouette 完全相同；目前没有证据说明 10D 带来额外价值。
  • 两个簇太粗，无法直接回答更细的 design knowledge / theory / method 结构。
  • 教程要求 manual inspection；当前 explorer 可以检查论文，但还没有形成盲审、记录和一致性指标。

Prior research 到底支持什么，不支持什么

有支持

  • 使用 dense text embeddings 表示文档。
  • 用 K-Means 做强制分配 baseline。
  • 用 DBSCAN/HDBSCAN 寻找密度簇并保留 noise。
  • 先用 UMAP 降维，再做 HDBSCAN，是已发表且常用的 text-topic pipeline。
  • 用 silhouette、coverage、cluster size 和人工判断共同评价。
  • 通过重采样或扰动检查聚类稳定性。

没有支持

  • 没有论文能证明 UMAP 在这 282 篇上一定比 raw space 好。
  • 没有论文能证明低 noise 就代表高质量主题。
  • 没有依据把 0.2864 silhouette 直接说成“最佳”，因为它只覆盖 19.1%。
  • 没有依据把 2D UMAP 上分开的颜色当作真实语义边界。
  • 没有依据把机器生成的 TF-IDF label 当作完成的人类解释。

为什么仍然值得做

这三个页面把老师提出的替代解释变成了可比较实验：是 raw embedding 没有密度结构，还是高维性让密度算法失效？

目前答案是：UMAP 改变了 HDBSCAN 的 coverage，但没有提高原始空间分离度，也没有给出更细、平衡的主题。

BERTopic 的研究为 embedding → UMAP → HDBSCAN → topic representation 提供了直接先例； Vizuara 教程为 Zhicheng 建议的具体操作顺序提供了可执行示例。 但对本项目而言，最重要的后续证据仍然要来自稳定性测试和领域专家检查。

已知问题：现在不能回避的地方

01

参数是 post-hoc 挑选的

生成器试了多个参数，再按“2–15 簇、最小簇至少 5、silhouette + 0.15 × coverage”挑最大值。 这适合探索，但会乐观偏差。需要冻结规则后在重采样数据上复验。

02

没有做 seed / bootstrap stability

目前只有固定 seed 的一次 UMAP。Ben-Hur et al. 提出的稳定性思路是扰动或子采样数据，再比较聚类是否重复出现。 如果换 seed 或去掉 10% 论文就完全改组，主题不能称为稳定。

03

没有完成领域专家盲审

自动指标衡量几何分离，不衡量“这个主题对 design knowledge 研究是否有意义”。 Chang et al. 的研究显示，自动模型指标与人类可解释性可能不一致。必须抽样论文做 topic / document intrusion 或等价的人审任务。

04

silhouette 与 coverage 不可拆开

raw HDBSCAN 的 0.2864 是只在 54 篇非 noise 论文上算的。它不能和 K-Means 的 282 篇全覆盖 silhouette 做无条件排名。

05

UMAP 会改变密度

普通 UMAP 优先保留邻域，不保证局部密度和所有全局距离。再用密度算法时，可能把 UMAP 制造的紧密区域误认为原始语义簇。 应报告多 seed、一致性，并考虑 PCA、densMAP 或 raw-space 结果作为敏感性分析。

06

2D 图只是显示，不是证据

三个页面共享一张独立 2D UMAP 布局。颜色分开不代表在实际 5D、10D 或 1024D 聚类空间里同样分开；坐标轴没有主题含义。

07

语料仍有重复题名

对当前 282 行按小写、移除标点和空白后审计，发现 7 组重复题名，共 14 行。 它们可能是不同版本或重复记录。重复点会人为增加局部密度，尤其影响 DBSCAN/HDBSCAN，必须逐组核对 DOI、作者和版本。

08

标签是机械生成，不是验证后的 codebook

当前簇名和关键词来自 cluster-level TF-IDF。它们用于帮助阅读，不是预设 codebook，也不是专家确认的理论类别。 “标签看起来合理”不能反向证明聚类正确。

09

只测试了一种 embedding 表示

三页固定 BGE-M3 是为了公平比较算法，但最终结论仍可能依赖文本拼接、passage 选择与 embedding model。 至少需要对 title+abstract-only、不同 passage budget 或另一个 embedding 做敏感性检查。

10

Page 2 与 Page 3 有方法重叠

Page 3 本质上是 Page 2 HDBSCAN 分支的 10D 版本。保留它的价值在于精确回应 Zhicheng 的建议； 如果 5D 和 10D 长期给出相同结构，最终界面可以合并为一个参数对照，而不是宣称两种独立方法。

在决定“用哪个方法”之前，建议按这个顺序执行

  1. 先清重复：核对 7 组重复题名，区分真正重复、会议/期刊版本和不同论文。
  2. 冻结候选规则：把允许的簇数、最小簇、coverage 下限和评价方式在看新结果前写死。
  3. 多 seed：每个 UMAP 设置至少运行 20–50 个 seed；比较 pairwise Adjusted Rand Index、cluster Jaccard 和 noise 一致性。
  4. 重采样：对论文做 80%–90% subsampling 或 bootstrap，至少 50 次；报告每个簇的稳定性，而不是只报告平均分。
  5. 同时报告三项：silhouette、coverage、cluster-size distribution。任何一个都不能单独决定胜负。
  6. 人类检查：每簇盲抽代表论文、边界论文和 noise；至少两位 reviewer 独立判断 coherence，再计算一致性。
  7. 解释 noise：不要自动回填。单独分析 noise 是否是跨主题论文、方法论文、文本缺失、重复版本或真正的弱亲和论文。
  8. 形成最终选择：只有同时满足稳定、可解释、覆盖目标和研究用途，才进入 final pipeline。
当前最诚实的汇报方式： “我们已经实现 raw-space、UMAP-before-clustering 和 Zhicheng UMAP+HDBSCAN 三类对照。 初步结果显示 UMAP 能显著改变 HDBSCAN 的 noise/coverage，但没有提高原始空间 silhouette， 且形成粗糙的 55/227 二分。下一步是重复数据清理、稳定性分析和盲审，而不是现在宣布赢家。”

  7. Grootendorst, M. (2022). BERTopic: Neural Topic Modeling with a Class-Based TF-IDF Procedure. 直接支持 embedding → UMAP → clustering → class-based TF-IDF 的文档主题路线。
  8. Narayan, A., Berger, B., & Cho, H. (2021). Assessing Single-Cell Transcriptomic Variability through Density-Preserving Data Visualization. Nature Biotechnology. 说明普通 UMAP 不保存原始局部密度，并提出 densMAP；这是 UMAP 后做密度聚类时的重要警告。
  9. Rousseeuw, P. J. (1987). Silhouettes: A Graphical Aid to the Interpretation and Validation of Cluster Analysis. silhouette 的原始定义；仍不能代替 coverage 与人工语义评价。
  10. Ben-Hur, A., Elisseeff, A., & Guyon, I. (2002). A Stability Based Method for Discovering Structure in Clustered Data. 支持通过子采样/扰动后的聚类相似度评估结构稳定性。
  11. Chang, J., Gerrish, S., Wang, C., Boyd-Graber, J. L., & Blei, D. M. (2009). Reading Tea Leaves: How Humans Interpret Topic Models. 说明自动模型质量与人类语义可解释性可能不一致，支持加入人类评价。
  12. Rashik, I., & Vizuara AI (2024). From Text to Insights: Hands-on Text Clustering and Topic Modeling — Part 1. Zhicheng 分享的 practical tutorial；提供执行示例，但不是同行评审证据。
